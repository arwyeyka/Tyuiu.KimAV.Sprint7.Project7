# Решение Sprint 7 (Вариант 7) — ТИУ
Предметная область: Домоуправление (учет квартир)
Разработчик: К.А.В.

Структура решения:
- Tyuiu.KAV.Sprint7.sln — файл решения для Visual Studio 2019/2022
- Tyuiu.KAV.Sprint7.Project.V7.Lib — библиотека классов с бизнес-логикой и DataService
- Tyuiu.KAV.Sprint7.Project.V7.Test — модульные тесты MSTest
- Tyuiu.KAV.Sprint7.Project.V7 — графическое приложение Windows Forms (.NET Framework 4.8)
- apartments_data.csv — демонстрационная база данных CSV

Инструкция:
1. Откройте `Tyuiu.KAV.Sprint7.sln` в Visual Studio.
2. Нажмите правой кнопкой мыши по `Tyuiu.KAV.Sprint7.Project.V7` -> 'Назначить запускаемым проектом'.
3. Нажмите F5 для запуска.
